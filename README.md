
## Sigma Folder

This application is for android devices only for the moment.

It has been tested only for a __Samsung Galaxy Fold 4__ foldable phone.
Nevertheless, it is not guaranteed from bugs, and often I fix this or that bug.

### Features of Sigma Folder

This is a __file explorer app__, designed to local files for now, with the capability to __copy/move a file or an entire folders content to a NAS__ (which was one of my requirements).

It has plenty of other nice features I added, most of them with the purpose of manage a video library:
* it can manage memos, linked to a file (it is hard-added to the end of the file, with a rich-text editor, color handling, HTML import) or to a folder (in that case, a dedicated hidden file is created in the folder, which allows to move the folder without losing its Sigma properties)
* there is a home view, which is some of a entry point to the app with customizable shortcut access to this or that local folder.
* Each file or folder can be tailored with a dedicated picture which can be grabbed from an internal simple navigator(log press on a picture triggers the collect of the picture, be careful, it does not works on all pictures. It works nice with Google page/Images/<images>). The picture can be adjusted.
* Some informations are added to files (extension and size) or folders (number of files inside, and number of folders inside)
* there are some basic file/folder operations: rename, move, delete, copy (not implemented for the moment), addition of a brother folder, of a child folder (for folders).
* It has a tag feature, for example some horror movies in a given folder can be tagged with a custom tag(title+color). Tags are definded inside a folder, it you move inside another folder, other tags will apply. You can distinguish tagged files/folders by the color of its border, which is the one of the tag. You can filter folders items by clicking on a tag.
